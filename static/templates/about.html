ABOUT THE PROJECT

PLANTARCARE

A college-level machine learning web application for plantar fasciitis risk prediction and educational foot-care guidance.

Machine Learning

A Random Forest classifier is trained on a synthetic academic dataset containing demographic, activity and symptom features.

Web Application

Flask connects the assessment form, model prediction, risk-rule layer, reports, exercises and games.

Project Scope

The application demonstrates a complete ML workflow from input collection to prediction and presentation.

The dataset supplied with this project is synthetic/demo data. It should not be interpreted as clinical evidence.
